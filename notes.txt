Login to your instance via SSH to run the commands.

### 3. Redeployment Commands
Copy and run these commands whenever you update your code:

```
# 1. Stop the currently running 
container
docker stop $(docker ps -q)

# 2. Remove the stopped container
docker rm $(docker ps -a -q)

# 3. Build the new Docker image 
(This installs new requirements)
docker build -t sentiment-app .

# 4. Run the new container on Port 
80
docker run -d -p 80:80 sentiment-app
```
### 4. Troubleshooting
If something breaks, check the logs:

```
docker logs $(docker ps -q)
```

### Required EC2 Inbound Rules
You need to add these two rules in your AWS Console under EC2 > Security Groups > Edit Inbound Rules :

Type Protocol Port Range Source Why is this needed? HTTP TCP 80 0.0.0.0/0 (Anywhere) Critical : Allows everyone on the internet to see your website. SSH TCP 22 My IP (Recommended) Allows you to connect via PuTTY and WinSCP to upload files.

If you don't add the HTTP (80) rule, the website will timeout when you try to visit it in the browser.
If you don't add the SSH (22) rule, WinSCP and PuTTY will fail to connect
